Measured Training

18 attempts: 16 completed, 1 diverged, 1 OOM. Each completed run processed 327.68M tokens. The lowest observed final validation loss was 1.3648 (perplexity 3.9149), at batch 64, peak learning rate 0.001 and seed 336. Ablations use the measured batch-32 control. Model selection used sampled validation loss and one seed.

Inference with Trained Weights

Request-local K/V state, RoPE offsets, rectangular causal masks and exact cropped-window rebuilds extend the original inference path. The inference-only export preserves all 22,696,448 parameters exactly. CPU generation in a fresh source directory, natural EOS continuation and all 30 timed comparisons passed output checks. The existing pinned dependency environment was reused.
